## 工程观察

- BMC legacy 数据中的事件类型字节可映射到 OSA、HYP 和 CSA；单凭源码不能证明每条记录都等同于一次独立临床事件。
- 公开 OSCAR legacy 解析将两个压力字节分别解释为 EPAP 和 IPAP。本项目因此将它们作为两个设备通道展示，同时保留 `pressure == epap` 兼容键；这不是原厂认证，也不是调压建议。
- 流量可能有非零基线，不能用零交叉直接推算呼吸次数。
- OSCAR 的 session 时间、设备摘要分钟数和波形包覆盖范围可能采用不同口径。缺失波形时不能用短波形覆盖时长替代摘要分母。
- 重复时间戳不一定代表重复样本；只要包内容不同，就必须保留样本并在时间轴上明确缺口和不确定性。

## 产品边界

首页把设备记录、程序计算和用户自述分开呈现。事件记录频率保持为估算指标，不自动升级为临床 AHI；软件不推断睡眠分期、血氧或压力处方，也不把记录段数量解释成开关机或醒来次数。

## 可重复验证

公开仓库只提供合成夹具。维护者可运行 `python3 -m unittest -v`，检查字段边界、日期编码、缩放、缺失处理、重复包、报告转义以及中英文导出。使用真实卡或原厂软件进行额外核对时，请把结果保留在仓库外，不要提交原始文件、导出报告或含日期/序列号的截图。
