# OSCAR 解析验证说明

本页定义公开仓库能够复核的验证边界。它不记录真实 SD 卡、患者日期、设备序列号、运行主机路径或部署地址。

## 已覆盖的公开边界

- `FORMAT.md` 记录本项目实际读取的 BMC U-20A 字段、指针边界、时间划分和压力通道命名。
- 合成测试覆盖 USR 历史/当前日区分、无效日期、循环指针、波形包校验、缩放、重复时间戳、时间缺口和导入失败回滚。
- 报告测试覆盖中英文 JSON、Markdown、HTML、手机版 HTML/PDF 数据接口，以及自述内容转义。
- 压力通道名称遵循公开 OSCAR legacy parser 的 EPAP/IPAP 解释，但仍明确标注“未与原厂软件逐项核验”。

## 不应从这些测试推出的结论

本项目没有在公开仓库中声称完成完整 OSCAR GUI 导入、SQLite 汇总、原厂 AHI 对账或临床验证。不同软件的 session 终点、摘要分钟数、波形覆盖和事件聚合可能不同；任何真实数据对账都必须在本地私密环境中完成，并单独记录软件版本与证据边界。

## 维护者工作流

1. 使用合成夹具运行 `python3 -m unittest -v`。
2. 对解析或字段命名有变化时，同步更新 `FORMAT.md`、界面说明和报告文案。
3. 若需要用真实卡交叉核对，只在仓库外保存结果；提交前检查 `git diff --cached`，确认没有原始数据、导出报告、真实日期、序列号、访问令牌或基础设施地址。
