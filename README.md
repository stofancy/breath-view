# 息览 · Breath View

在 Linux 桌面离线读取 BMC U-20A 呼吸机 SD 卡，展示中文趋势和单夜波形。

## 启动

应用菜单搜索 **息览**，或运行：

```sh
./launch.sh
```

当前电脑已有 Python 3、PySide6 与 NumPy。迁移到其他电脑时可在 Python 虚拟环境中安装 `requirements.txt`，再用该环境的 Python 执行 `app.py`。

## 使用

- 顶部工具栏选择 SD 卡根目录，确认界面中的导入路径并点击导入。
- 长期趋势选择 7 / 30 / 90 天或全部，以最近记录日为截止日。
- 点击治疗日或“查看最近波形”进入详情。拖拽曲线缩放；点击事件查看附近 5 分钟；滑条和箭头平移；“整晚”复原。
- CSV 导出包含全部摘要，未结算日及缺失值留空。
- 数据与说明页展示解析边界、来源、导入时间、读取失败区间。

数据放在 `~/.local/share/breath-view/`，不写入 SD 卡。每次成功导入保留一个独立快照，`current` 指向本次快照；旧快照保留在磁盘，不自动删除。界面当前显示最新导入快照。拔卡后仍可查看。

所有页面与图表本地提供，不使用 CDN 或外部服务。仅监听 `127.0.0.1` 的随机端口，并使用随机能力 URL。无账户、遥测、云同步或诊断建议。

## 命令行

```sh
python3 app.py --import-card /path/to/card
python3 app.py --serve         # 浏览器模式，打印本地网址
python3 app.py --home /path/to/archive
python3 -m unittest -v
```

## 精度与支持范围

目前只接受已经用实际数据验证的 U-20A。详细格式证据和尚未确认的字段见 [FORMAT.md](FORMAT.md)。事件指数由条目数量计算，不承诺等同原厂 AHI；不推断睡眠分期，不展示未确认的设置、血氧和鼾声，不给调压建议。

SD 卡发生 I/O 错误时，摘要读取失败会终止导入；波形不可读的 1 MiB 区间记录在清单并用无效包占位，解析时丢弃并断开曲线。副本的 SHA-256 是本地副本的校验值，有缺口时不代表完整原文件。导入失败不覆盖此前可用的数据。

图表概览采用极值保留抽样；短于约 44 秒的流量区间可显示全部 25 Hz 原始点。跨开关机、不可读数据和缺失区间不插值。时间轴保留呼吸机时钟，不依赖电脑时区。
